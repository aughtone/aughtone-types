# Research & Development Logs

One document per question that had to be worked out: the options compared, what was refuted and why, the dead ends walked far enough to rule out, and what it all recommends. A RAD sits upstream of a decision — it explores and recommends, it does not commit.

This is where undecided things legitimately live: open questions, deferred options, approaches parked rather than killed. A recommendation that hardens into a commitment graduates to a Decision, which is append-only and carries no open questions.

Not here: the choice itself once made (that is a Decision), what a feature must do (that is a Requirement), or how something currently works (that is a Specification).
