# Architecture Decision Records

One document per hard-to-reverse choice: the forces at the time, what was
decided, what was given up, and — most usefully — which alternatives lost and
why. This section is append-only. A decision that stops being true is
superseded by a new record, never edited into agreement with the present.

Not here: how something currently works (that is a Specification), or an
investigation that has not landed on a choice yet (that is Research).
