# Working in this repository

**Read [AGENTS.md](AGENTS.md) and follow it.** It is the authoritative set
of rules for any agent working here, and it applies to you. This file
exists only so you find them; do not treat it as a substitute for reading
them.

The rule most often broken, stated here so it cannot be missed by an agent
that stops at this file: **this repository is public and its history is
permanent.** Never commit real names, personal email addresses, hostnames,
absolute home paths, employer or client names, private project names,
tracker keys or instance URLs, or anything about the maintainer's business
or working habits. Verbatim quotes from a working conversation leak all of
that at once, and documents generated straight from a conversation — RADs,
ADRs, design notes, session summaries — are where it happens.

Document the pattern, not the person. AGENTS.md explains what that means,
and lists the narrow attributions that are meant to be here and must not be
stripped.
